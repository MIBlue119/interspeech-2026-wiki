# Interspeech 2026 LLM Wiki

> An open, agent-searchable knowledge base of [Interspeech 2026](https://www.isca-archive.org/interspeech_2026/index.html) papers — built in the [OKF / llm-wiki](https://github.com/karpathy) style so you can clone it and ask **Claude Code / Codex / any coding agent** questions about this year's speech research.

**Why this exists**

- 📖 **Read the conference differently** — every paper gets a compiled wiki page (problem → method → results → code), not a 10-page PDF you'll never open.
- 🔎 **Search by meaning** — clone the repo, point your agent at it (optionally with [zvec-grep](https://github.com/zvec-ai/zvec-grep) semantic search), and ask things like *"which papers do low-resource TTS with discrete tokens?"*
- 🤝 **Find people, not just papers** — companies can find research groups; researchers can find collaborators. Authors are welcome to claim their entry via PR and add contact / collaboration info.
- 🌱 **Community-built** — adding a paper is a one-file PR. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Quick start (humans)

Browse the [paper table](#papers-with-open-source-code) below or start at [`wiki/index.md`](wiki/index.md).

## Quick start (AI agents)

```bash
git clone https://github.com/MIBlue119/interspeech-2026-wiki
cd interspeech-2026-wiki
claude   # or codex, or any agent — then just ask about the papers
```

Agents: read [`AGENTS.md`](AGENTS.md) for how this repo is laid out and how to search it.

Optional semantic search with zvec-grep:

```bash
./scripts/setup-zg.sh   # installs/indexes zg for this repo
zg "contextual biasing for rare words"
```

## Repo layout

| Path | What it is |
|---|---|
| `wiki/papers/*.md` | One OKF-style compiled page per paper (frontmatter + original summary). **Not** the paper full text. |
| `data/papers/*.yaml` | One metadata file per paper (title, authors, DOI, code links…). The table below is generated from these. |
| `cmd/iswiki/` | Go CLI: scrape the ISCA index, validate metadata, regenerate this README, fetch PDFs locally. |
| `sources/` | *(gitignored)* PDFs you fetch locally for deep reading — never committed. |

## Local full-text search (optional)

Paper full texts are **not** in this repo (see licensing below). To build a private, local full-text index:

```bash
go run ./cmd/iswiki fetch --insecure     # downloads PDFs into sources/ (gitignored)
./scripts/setup-zg.sh                    # index wiki + sources with zvec-grep
```

> Note: `--insecure` exists because isca-archive.org currently serves an expired TLS certificate. Remove the flag once ISCA fixes it.

## Contributing

One paper = one YAML file + one wiki page. `iswiki` generates the stubs for you — see [CONTRIBUTING.md](CONTRIBUTING.md). Authors: PRs that claim your own paper entry (contact info, lab link, "open to collaboration") are especially welcome.
