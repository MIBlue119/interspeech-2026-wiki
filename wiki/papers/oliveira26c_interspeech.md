# The TinyExplorer Ecosystem: Open Tools for Studying Infants' Auditory and Visual Experiences

**TL;DR** — An open-source platform pairs child-friendly wearable headcams with local AI annotation tools to make studying infants' everyday auditory and visual environments scalable instead of painstakingly manual.

## Problem

Studying young children's everyday learning environments is difficult because existing methods struggle to capture the dynamic, multimodal, socially embedded nature of children's naturalistic experiences, and headcam-based research is limited by both hardware safety/comfort concerns and the time cost of manual audio/video annotation.

## Method

The authors build the TinyExplorer Ecosystem, an open-source platform combining wearable egocentric recording hardware (TinyExplorer Gear) with locally run AI-powered annotation tools (TinyExplorer Detection App), which currently automates face detection and is being extended to hand detection, hand-object interaction, and audio processing.

## Results

As an open tools/infrastructure paper, it reports the platform's current capabilities (automated face detection, with further annotation modules in development) rather than a benchmark accuracy result; it is presented as supporting scalable, reproducible research on children's real-world learning environments.
