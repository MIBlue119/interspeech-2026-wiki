# TSExplorer: An interactive data annotation and exploration tool for time-series data

**TL;DR** — A cross-platform tool lets researchers visually explore, annotate, and refine labels on high-dimensional time-series data through multiple complementary 2D views.

## Problem

Researchers working with high-dimensional time-series data (including speech features) need general-purpose tools for exploratory analysis, annotation, and label refinement that support diverse workflows.

## Method

TSExplorer provides multiple complementary 2D visualizations derived from high-dimensional feature representations, supporting exploratory data analysis, annotation of unlabeled or partially-labeled datasets, comparison of feature representations, and post-hoc inspection/refinement of existing labels with interactive visual feedback.

## Results

As a tool paper, the abstract reports no quantitative benchmark results; it describes the tool's supported workflows and visualization capabilities.
