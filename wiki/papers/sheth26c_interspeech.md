# ELSI: An Interface for Standardizing Child-Centered Datasets, Applying Machine Learning Models, and Extracting Metrics

**TL;DR** — ELSI is an open-source, no-code interface that lets language-acquisition researchers standardize child-centered audio datasets, run ML models like speaker diarization, and extract metrics such as vocalization counts and conversational turns.

## Problem

Researchers studying language acquisition in diverse communities need to standardize child-centered datasets and apply machine learning tools (e.g. diarization, phoneme counting), but doing so typically requires advanced programming skills they may not have.

## Method

ELSI (the ExELang Legacy Support Interface) is an open-source interface that lets users of any technical background standardize child-centered datasets, apply ML models trained on child-centered audio, and extract key metrics such as child vocalization count, adult vocalization count, and conversational turns.

## Results

The Show and Tell demonstrates dataset standardization, model execution, and metric extraction through the interface, rather than reporting a benchmark result.
