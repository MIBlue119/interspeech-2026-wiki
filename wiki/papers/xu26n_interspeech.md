# Automatic Graphical Representations of Language for Dementia Detection

**TL;DR** — Modeling how a speaker moves through content units of the "Cookie Theft" picture description task as a temporal graph, instead of just their spatial distribution, automates a richer, narrative-dynamics view of cognitive-linguistic assessment.

## Problem

The Cookie Theft picture description task is widely used to assess cognitive-linguistic ability via content information units (CIUs), but prior CIU-based studies rely on manual annotation and mostly examine spatial CIU distributions, leaving temporal narrative dynamics underexplored.

## Method

The authors build an automated framework for identifying CIUs from picture descriptions and modeling transitions between CIUs as a temporal graph, extracting graph-based features to characterize narrative organization and temporal dynamics, with a visualization showing how speakers traverse picture content over time.

## Results

The framework extends CIU-based analysis beyond spatio-semantic representations to capture temporal narrative dynamics, offering a scalable, automated approach for assessing cognitive abilities; the abstract does not report a specific classification accuracy figure.
