# EchoLoc: Audio-Aware Object Grounding via Joint Heatmap and Box-Level Localization

[PDF](https://www.isca-archive.org/interspeech_2026/shin26b_interspeech.pdf) · [ISCA page](https://www.isca-archive.org/interspeech_2026/shin26b_interspeech.html) · [DOI](https://doi.org/10.21437/Interspeech.2026-2320)

**TL;DR** — EchoLoc is an audio-aware object grounding framework that jointly trains heatmap and box prediction modules, achieving +2.58% and +17.08% relative improvements in adaptive cIoU and AUC on Flickr-SoundNet-Test over state-of-the-art methods.

## Problem

Conventional vision-language grounding models rely heavily on complete, explicit captions and struggle to incorporate non-visual cues like sound, whereas self-supervised sound source localization models produce blurry heatmaps and lack explicit object-level bounding boxes. Addressing this requires a framework that can learn fine-grained object bounding boxes from scarce audio-visual annotations without relying on noisy or missing textual supervision.

## Method

EchoLoc adapts a query-based transformer detector (MDETR) combined with a frozen PANNs CNN14 audio encoder and a ResNet-101 visual backbone to perform early cross-modal fusion. It employs two parallel modules: an audio-conditioned box prediction branch trained using Hungarian matching against pseudo-boxes, and a heatmap prediction module trained via spatial and global contrastive losses. The model uses diverse audio-conditioned candidate boxes generated by object queries and selects the one with the highest audio-visual similarity based on the heatmap guidance. Training is performed on VGGSound and Flickr-SoundNet-144K using a batch size of 32 for 40 epochs on a single RTX 3090 GPU.

## Results

Evaluated on VGG-SS and Flickr-SoundNet-Test datasets using cIoU and AUC metrics (including adaptive variants), EchoLoc scores 36.36 cIoU and 38.28 AUC on VGG-SS, and 84.34 cIoU, 88.22 adaptive cIoU, and 79.99 adaptive AUC on Flickr-SoundNet-Test. An ablation study demonstrates that incorporating the box prediction module on top of the heatmap-only model increases VGG-SS cIoU from 31.73 to 36.36 and AUC from 32.06 to 38.28. Baseline comparisons show superior adaptive performance in handling ambiguous, multi-instance audio-visual scenes.

## Applications

Engineers and researchers working on multimodal perception, robotics, and video analysis can use EchoLoc for precise sound source localization and object grounding in unconstrained audio-visual environments.

## Limitations

The framework's box-level predictions are bounded by the quality of the underlying heatmap estimation, since both pseudo-supervision generation and final box selection rely directly on heatmap-based audio-visual similarities.
