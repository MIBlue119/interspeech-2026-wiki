# PyPhonPlan: Simulating phonetic planning with dynamic neural fields and task dynamics

**TL;DR** — An open-source Python toolkit lets researchers build dynamic-neural-field models of phonetic planning and articulation, with a worked example simulating a production-perception loop.

## Problem

Modeling phonetic planning with dynamical, neurally-grounded frameworks (dynamic neural fields plus task dynamics) has lacked accessible, reusable software tooling.

## Method

PyPhonPlan provides modular components for defining planning, perception, and memory fields and their coupling, gestural inputs, and translating field activation profiles into tract-variable trajectories, and demonstrates the toolkit with an example simulating production/perception loops using a coupled memory field.

## Results

The example application demonstrates the framework's ability to model interactive speech dynamics with representations that are temporally principled, neurally grounded, and phonetically rich; the paper reports no quantitative benchmark results.

## Code

Code released by the authors as open-source software (executable examples included); see the paper for the repository link.

## Applications

Research tool for phoneticians and computational modelers studying speech production, planning, and production-perception interaction dynamics.
