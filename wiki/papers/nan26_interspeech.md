# SpeechBench: A Unified Speech Annotation and Analysis Tool

**TL;DR** — A GUI tool lets non-technical users build multi-step, model-assisted pre-annotation pipelines for domain-specific speech data, with private-server deployment for data privacy.

## Problem

Existing speech annotation tools don't adequately support model-assisted manual annotation workflows (using general-purpose models to pre-annotate domain-specific data, followed by human refinement), leaving annotation slow, inefficient, and hard to scale.

## Method

SpeechBench integrates trained models for a range of speech processing tasks and provides a graphical interface for building multi-step, model-based pre-annotation pipelines, lowering the barrier for non-technical annotators, and supports deployment on private servers for strict data privacy requirements.

## Results

As a tool paper, the abstract reports no quantitative benchmark results; it describes the integrated annotation and analysis workflow.
