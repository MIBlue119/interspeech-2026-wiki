# Label Correction Enhanced Dual-Stream Multiple Instance Learning for Weakly-Supervised Depression Detection in Speech

**TL;DR** — Combining a label-correction module with dual-stream multiple instance learning helps automatic depression detection cope with both inaccurate and imprecise weak labels.

## Problem

Automatic Depression Detection (ADD) from speech in weakly-supervised settings faces both inaccurate labels and inexact (coarse) labels, and existing speech-based ADD methods fail to jointly address both issues.

## Method

LC-DMIL (Label Correction enhanced Dual-stream Multiple Instance Learning) combines a label correction module that fixes inaccurate labels through fused likelihood-ratio-based and prototype-based correction strategies with a depression detection module that uses a dual-stream multiple instance learning approach to handle inexact labels.

## Results

Experiments on weakly-supervised speech-based depression detection data show the approach performs effectively for weakly-supervised speech-based ADD.
