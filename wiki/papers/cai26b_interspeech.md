# Enhancing Temporal Prediction Consistency for Short-Duration Acoustic Scene Classification via Semantic Adversarial Training

[PDF](https://www.isca-archive.org/interspeech_2026/cai26b_interspeech.pdf) · [ISCA page](https://www.isca-archive.org/interspeech_2026/cai26b_interspeech.html) · [DOI](https://doi.org/10.21437/Interspeech.2026-1955)

**TL;DR** — The Semantic Adversarial Training (SAT) framework improves short-duration acoustic scene classification by using adversarial learning to eliminate temporal prediction inconsistencies, achieving an overall accuracy of 63.5% on the 1-second TAU20 dataset.

## Problem

Standard acoustic scene classification (ASC) models suffer severe performance degradation when restricted to short observation windows (e.g., 1 second) because they rely heavily on foreground events rather than background textures, leading to temporal prediction instability. To quantify this behavioral divergence, the authors introduce the Local-Global Prediction Discrepancy (LGPD) metric, which calculates the Kullback-Leibler divergence between full long-duration predictions and truncated short-duration predictions. The analysis proves that model accuracy drops heavily as prediction inconsistency increases, highlighting the need to enforce temporal prediction consistency.

## Method

The SAT framework utilizes a TF-SepNet feature extractor feeding into two parallel branches: a scene classifier optimized via cross-entropy loss, and an auxiliary event discriminator optimized via multi-label binary cross-entropy loss using pseudo event labels generated by a frozen BEATs model. A Gradient Reversal Layer (GRL) is placed before the event discriminator with a reversal scalar -alpha_adv in [-1, 0] to force the feature extractor into a min-max game that discards duration-dependent semantic variances while retaining scene-discriminative features. The training uses 150 epochs, a batch size of 512, the Adam optimizer, exponential learning rate warm-up, and various augmentations including Mixup, Freq-MixStyle, and DIR-Aug. The adversarial loss weight lambda_adv is set to 5, the discriminator learning rate is scaled by 0.01, and the feature extractor updates five times per iteration.

## Results

Evaluated on the TAU Urban Acoustic Scenes 2020 Mobile Development Dataset (TAU20) by slicing 10-second recordings into non-overlapping 1-second segments, SAT achieves a headline overall accuracy of 63.5% compared to the 59.6% baseline. On the unstable subset (top-50% LGPD), SAT reaches 50.9% accuracy, yielding a +7.8% improvement over the baseline (43.1%) and reducing the stability gap from 33.0 down to 25.2. It outperforms alternative frameworks including Multi-Task Learning (60.3%), Knowledge Distillation (61.1%), and Joint Learning (61.8%). Ablations on sound event taggers demonstrate that stronger taggers (CNN14 at 61.8%, PaSST at 62.5%, and BEATs at 63.5% overall) systematically improve performance on the unstable subset.

## Applications

Engineers building responsive, low-latency environmental sensing systems and on-device acoustic monitoring applications that require accurate classification within short observation windows.

## Limitations

The framework relies on off-the-shelf pre-trained sound event taggers to supply pseudo labels, which can potentially introduce label noise.
