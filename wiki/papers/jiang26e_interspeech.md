# Cognitive-Heuristic Guided Multimodal Data Augmentation for Alzheimer's Disease Detection Using LLM and TTS

**TL;DR** — Generating extra training data that explicitly mimics Alzheimer's-related linguistic and acoustic patterns — via LLM text generation and attribute-guided TTS — boosts speech-based Alzheimer's detection under data scarcity.

## Problem

Speech is a promising non-invasive biomarker for Alzheimer's disease (AD) detection, but training data is severely scarce, and existing augmentation methods in text or speech tend to neglect the cognitively relevant patterns that actually distinguish AD speech.

## Method

The authors propose a cognitive-heuristic guided multimodal generative augmentation framework that explicitly incorporates AD-related cognitive decline patterns: retrieval-augmented generation with LLMs produces cognitively informed synthetic text, and an attribute-guided TTS system reproduces AD-related acoustic features from it.

## Results

Across multiple benchmarks, the augmented data consistently improves detection performance, demonstrating the value of cognition-driven multimodal synthesis for speech-based AD detection.
